# Portfolio Microsoft 365 - Angular Starter

Base Angular standalone pour présenter un profil Consultant Microsoft 365 / Power Platform.

## Installation

```bash
npm install
npm start
```

## Personnalisation rapide

- Modifier les textes et projets dans : `src/app/core/data/portfolio.data.ts`
- Modifier les contacts dans : `src/app/features/home/components/contact/contact.component.ts`
- Ajouter ton CV dans : `src/assets/cv-claude-ndja.pdf`
- Changer les couleurs dans : `src/styles.css`

## Sections incluses

- Hero premium
- Statistiques
- Profil CV
- Compétences Microsoft 365
- Réalisations Office 365 / Power Platform
- Timeline expérience
- Contact
